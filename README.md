# Project 2 - Insurance Data Analysis Dashboard

## Overview

This project is an interactive Power BI dashboard developed for analyzing insurance policy, customer, premium, coverage, and claim data.

The dashboard provides a clear view of insurance performance and helps identify important trends across policies, customers, claims, and demographics.

---

## Dashboard Preview

### Insurance Dashboard

<img src="https://raw.githubusercontent.com/satyamsky801/project-2/main/assets/insurance-dashboard.png" width="100%">

**Dashboard Overview:**  
This dashboard provides a comprehensive overview of the insurance business.  
It presents key KPIs such as Premium Amount, Coverage Amount, and Claim Amount.  
Interactive filters allow users to analyze policies and customers based on different dimensions.  
Charts and visualizations help identify trends in premium, claims, policy types, and customer demographics.  
The dashboard is designed to support quick and effective business decision-making.

### Insurance Data View

<img src="https://raw.githubusercontent.com/satyamsky801/project-2/main/assets/insurance-data-view.png" width="100%">

**Data Analysis View:**  
This view presents the underlying insurance data used for the dashboard analysis.  
It includes policy numbers, customer information, claim details, age, gender, premium, and coverage amounts.  
The data contains multiple dimensions such as policy type, year, quarter, month, and day.  
These fields are used to build relationships, calculations, and interactive Power BI visualizations.  
The structured data model helps generate meaningful insights from the insurance dataset.
