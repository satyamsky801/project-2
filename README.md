# Project 2 - Insurance Data Analysis Dashboard

## Overview

This project is an interactive Power BI dashboard developed for analyzing insurance policy, customer, premium, coverage, and claim data.

The dashboard provides a clear view of insurance performance and helps identify important trends across policies, customers, claims, and demographics.

## Key Features

- Policy analysis
- Customer analysis
- Premium Amount analysis
- Coverage Amount analysis
- Claim Amount analysis
- Claim Status analysis
- Active vs Inactive policy analysis
- Gender-wise customer analysis
- Policy Type analysis
- Age-group analysis
- Interactive filters and slicers
- DAX measures
- Data modeling
- Interactive data visualization

## Key KPIs

| KPI | Description |
|---|---|
| Premium Amount | Total premium generated |
| Coverage Amount | Total insurance coverage |
| Claim Amount | Total claim amount |
| Active Policies | Number of active policies |
| Inactive Policies | Number of inactive policies |
| Claims | Claim status and distribution |

## Dashboard Analysis

### Premium Amount by Policy Type

The dashboard compares premium amounts across different insurance policy types such as:

- Travel
- Health
- Auto
- Life
- Home

### Active vs Inactive Policies

The dashboard provides a comparison between active and inactive insurance policies.

### Claim Status

Claims are analyzed based on their status:

- Pending
- Rejected
- Settled

### Customer Demographics

Customer information is analyzed using:

- Gender
- Age group
- Customer ID
- Policy information
